# Neural Signatures

Official implementation accompanying the TMLR 2025 paper
**"Neural Signatures for Program Semantics (Extended)"**.

> **Status: released.** This repository tracks the v1.0.0 release. The code,
> configuration files and evaluation scripts below match the published version.

## Layout

```
src/         library code
configs/     experiment configuration
scripts/     entry points for training and evaluation
tests/       smoke tests
```

## Quick start

```bash
python -m pip install -r requirements.txt
bash scripts/run.sh --config configs/base.yaml
```
